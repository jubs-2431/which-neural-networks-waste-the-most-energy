# Paper Versions

This folder collects the current paper drafts in one place.

## HPEC 2026

- `HPEC2026_Submission.tex`: IEEEtran source for the HPEC 2026 submission draft.
- `HPEC2026_Submission.pdf`: compiled HPEC 2026 submission draft.
- `HPEC2026_Upload_Copy.pdf`: same HPEC PDF content with a simple upload-safe filename.

## FTC 2026

- `FTC2026_Anonymous_Submission.tex`: anonymized FTC 2026 source.
- `FTC2026_Anonymous_Submission.pdf`: compiled anonymized FTC 2026 submission.

## Revised Manuscript

- `Revised_IEEE_Style_Manuscript.tex`: earlier revised IEEE-style manuscript source.
- `Revised_IEEE_Style_Manuscript.pdf`: compiled earlier revised manuscript.

Some root-level paper files are kept for compatibility with existing scripts
and prior links. This folder is the organized collection of the available
versions.
